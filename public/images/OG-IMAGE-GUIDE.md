# Open Graph Image Guide

## Required Image

Create an Open Graph image at: `/public/images/og-image.jpg`

## Specifications

- **Dimensions:** 1200 x 630 pixels (required for Facebook/LinkedIn)
- **Format:** JPG or PNG
- **File size:** Under 1MB
- **Safe zone:** Keep text/logo within center 1200 x 540px (avoid edges)

## Design Recommendations

### Content to Include:
1. **InterProFinland Logo** (top or center)
2. **Tagline:** "Supporting International Professionals in Finland"
3. **Background:** Use brand colors
   - Primary: `#131f5b` (Navy blue)
   - Accent: `#4169E1` (Royal blue)
   - Light: `#F8F9FA`

### Design Tips:
- Use high contrast for readability
- Keep text large (minimum 40px font size)
- Include visual elements (icons, patterns)
- Test how it looks as a small thumbnail

## Quick Creation Tools

### Online Tools (Free):
1. **Canva**: https://www.canva.com/
   - Template: "Facebook Post" → Resize to 1200x630
   
2. **Figma**: https://www.figma.com/
   - Create frame: 1200 x 630px
   
3. **Adobe Express**: https://www.adobe.com/express/
   - Social media template
